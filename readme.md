# 📘 FB Clone Website

A **Facebook Clone Website** developed as a practice project during our **Git & GitHub tutorial**. This project was created to understand the basics of website development along with Git version control, repository management, commits, branches, and pushing projects to GitHub.

## 🚀 Project Overview

**FB Clone Website** is a front-end clone inspired by the basic layout and user interface of Facebook.

The main purpose of this project is **learning and practice**, especially understanding how a web development project can be managed using **Git and GitHub**.

This project demonstrates a simple social-media-style interface containing common elements such as navigation, user information, posts, and other Facebook-inspired UI components.

> ⚠️ **Disclaimer:** This is an educational project created for learning purposes. It is not affiliated with, endorsed by, or connected to Facebook/Meta.

## 💻 How to Run the Project

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/FB-CLONE-WEBSITE.git
```

### 2. Open the Project Folder

```bash
cd FB-CLONE-WEBSITE
```

### 3. Run the Website

Open the `index.html` file in your web browser.

You can also open the project using **Visual Studio Code** and use the **Live Server** extension if available.
